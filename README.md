# AlexHelp.com - Law Offices of Alex Poberesky

A modern, SEO-optimized website for the Law Offices of Alex Poberesky, P.A. Built with Astro, Tailwind CSS, and deployed on Vercel.

## Overview

This website redesign transforms the existing WordPress site into a fast, modern, and highly optimized static site while preserving all SEO value and expanding content coverage.

### Key Features

- **59 pages** covering all practice areas, locations, and content
- **100% static** - No server-side rendering required
- **Mobile-first** responsive design
- **SEO optimized** with schema markup, sitemaps, and meta tags
- **Accessibility** compliant (WCAG 2.1 AA)
- **Performance** optimized (targeting Lighthouse 95+)
- **Multilingual ready** - Supports 5 languages

## Tech Stack

- **Framework**: [Astro](https://astro.build/) 4.x
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) 4.x
- **Icons**: [Lucide](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com/)
- **Forms**: [Web3Forms](https://web3forms.com/)
- **Content**: Astro Content Collections (MDX)

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone [repository-url]
cd alex-help

# Install dependencies
npm install

# Start development server
npm run dev
```

### Development Commands

```bash
npm run dev      # Start dev server at localhost:4321
npm run build    # Build for production
npm run preview  # Preview production build locally
```

## Configuration

### Environment Variables

Copy `.env.example` to `.env` and configure:

```env
# Web3Forms - Get key at https://web3forms.com/
WEB3FORMS_ACCESS_KEY=your_access_key_here

# Google Analytics
GA_MEASUREMENT_ID=G-XXXXXXXXXX
```

### Forms Setup

1. Create a Web3Forms account at https://web3forms.com/
2. Add your access key to the environment variables
3. Update the hidden `access_key` field in form components

### Analytics Setup

1. Create a Google Analytics 4 property
2. Add the measurement ID to environment variables
3. Uncomment the GA script in `BaseLayout.astro`

## Content Updates

### Adding Blog Posts

Create a new MDX file in `src/content/blog/`:

```mdx
---
title: "Your Post Title"
description: "Brief description"
publishDate: 2024-01-20
author: "Alex Poberesky"
category: "Personal Injury"
tags: ["keyword1", "keyword2"]
---

Your content here...
```

### Updating Testimonials

Edit `src/data/testimonials.ts` to add or modify client testimonials.

### Adding Locations

1. Add location data to `src/data/locations.ts`
2. Create a new page in `src/pages/[location-slug].astro`
